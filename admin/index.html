Редактирование сайта

Изменения сохраняются через GitHub. Для редактирования войдите в аккаунт с правами на репозиторий сайта. Данные доступа вводятся только на GitHub.

Изменить страницу, меню и контакты ↗Открыть файл страницы в редакторе GitHub. Для этого требуется редактирование HTML.Загрузить фотографии ↗Добавить файлы в репозиторий. Чтобы заменить изображение на сайте, также измените его имя в index.html.

Сохраните изменения кнопкой Commit changes. Сайт обновится после сборки GitHub Pages.
